# Supplied anatomy model

`uterus.fbx` and `Image_0.png` were supplied by the DAI team in this conversation.
The source/creator/licence were not provided. Retain these files locally for the
requested prototype; obtain the creator's required licence/attribution before
external distribution. This note does not assert an open licence.

Inspection: one mesh, 61,635 vertices, no animation clips, one texture atlas.
The viewer preserves the model's proportions; it does not claim a separate fetus
or gestationally accurate anatomy. The week preview uses a separate procedural
illustration, labelled as such. No model image is a patient's scan.
